I don't have a favourite game as I tend to play one game for weeks on end and then switch to another. However, the games that I will always go back to are Terraria, Minecraft, For Honor and many others, but I chose ULTRAKILL because it is the game that I have started to play again as a new update recently came out and it is still as good as if I started playing it for the very first time, anyways, let's talk more about ULTRAKILL

This video game can be explained by so many people in so many different ways, so I will use the developers words

ULTRAKILL is a fast-paced ultra-violent retro FPS that combines the skill-based style scoring of character action games with the unadulterated carnage inspired by the best shooters of the '90s. Rip apart your foes with varied destructive weaponry and shower in their blood to regain your health.

The games that ULTRAKILL fuses together are classic shooters like Quake, modern shooters like Doom (2016), and character action games like Devil May Cry.

The reason I find this game so fun is all the different ways that the weapons can be combined into one attack. This is known as "tech". The other reasons are the way the game presents its challenges, the speed at which you can move, the easter eggs, the indie production company, This will all be explained more on the Favourites page

This game is set in a creative and scary alternate future where the great war never ended and people just kept developing new technology to fight, this is a rather gruesome game where you do a lot of killing (as the name implies) and the reason for this killing is becuase it was what the machine, V1 (the robot you play as) was made to do, and it does this very well. Although you just kill, the game has an interesting universe which I will explain more about in the Story page
